Quick Admin Guide

Welcome to the Damino's Pizza Admin panel. You can easily manage the menu items, prices, descriptions, and business information. Because this website is a serverless static application, any changes you save are stored in your browser's local cache.

To make your changes visible to customers visiting the website:

1 Update Info

Go to the tabs on the left to add items, modify prices, or change WhatsApp contact details.

2 Download Data

Click the Publish & Download button on the top right to download a file named data.json.

3 Replace File

Upload that downloaded data.json file into your website folder (e.g., via your hosting File Manager or FTP), overwriting the old one.

Complete Deploy Guide

Because this website is a direct front-end application with no centralized server databases, it is fast, secure, and 100% free to host. To apply your changes globally so customers can see them:

1 Download the configuration file

Click the Publish & Download button at the top right of this dashboard page. This generates a file named data.json containing all your settings, menu changes, and deals.

2 Upload the file to your hosting server

Open your web hosting panel (e.g. cPanel, Hostinger File Manager, GitHub, Vercel, or Netlify) and go to the public root folder (often named public_html or similar) where the website files are located.

Upload the downloaded data.json file, overwriting the existing data.json in that folder.

3 Clear browser cache (if needed)

Because the app is a Progressive Web App (PWA), it caches pages to load instantly and run offline. Once you replace the file, the service worker will detect the change on next load. To see changes immediately, close and reopen your browser tab, or perform a hard refresh (Ctrl + F5 or Cmd + Shift + R).

Pro-Tip: Local Backup

Keep a copy of your downloaded data.json file on your computer. If you ever use a different computer or clear your browser data, you can click the Import JSON button at the top to load your settings back into this editor!
